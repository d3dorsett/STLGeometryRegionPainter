Chrome or Edge on a desktop with plenty of RAM is recommended.

Import performs a topology and winding check before painting. It attempts safe orientation correction and small-hole closure, without deleting faces. Unresolved defects are reported; a PASS does not guarantee OrcaSlicer acceptance.

2. Define regions

Click a face to flood-fill neighboring triangles. Growth stops at sharp edges, disconnected geometry, or the face limit. Smart contour compares each triangle with the clicked surface, reducing spillover around bends. Sphere and cylinder modes constrain the fill to a 3D volume. Lower edge angles stop growth at smaller bends. These tools do not automatically recognize anatomical parts.

3. Paint

Choose color for selected slot
#000000

The four slots are White, Black, Red and Yellow by default. Customizing a slot changes its color without adding a fifth slot. Select a color, then click the image to fill the selected connected surface. Drag to rotate, scroll to zoom.

4. Export

Export uses OrcaSlicer paint_color triangle assignments and four filament slots. The included reference project settings may change your active printer/slicer profile; verify printer, material and temperatures before slicing.

5. Optional mesh tools

These operations are optional. Normal workflow: Load model → Define regions → Paint → Export. Save an exported backup before modifying geometry.

Experimental QEM reduction uses guarded edge collapses, protects color boundaries, and validates open/over-connected edges before accepting the result. The selected retention target is not guaranteed. Reduction cannot be undone.

Optional topology-aware repair tests coordinated groups of duplicate faces, accepting changes only if open edges and winding errors do not increase and over-connected edges decrease. Repair may change mesh connectivity and cause paint fills to cover larger regions. It does not run automatically on import. Rebuild geometry adjacency after repair before painting; verify the exported 3MF in OrcaSlicer.
